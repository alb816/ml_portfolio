# Линейная алгебра для машинного обучения

В этом разделе собраны реализации базовых операций линейной алгебры,
которые используются в алгоритмах машинного обучения.

## Что реализовано
- операции с матрицами и векторами
- скалярное и матричное произведение
- итератционные методы решения СЛАУ
- метод нахождения приведенной ступенчатой формы
- транспонирование и изменение формы матриц
- HDC - Hyperdimensional Computing используемый в основном для задач классификации
- собственные значения и векторы
- сингулярное разложение (SVD)

## Инструменты
- Python
- NumPy
- Matplotlib

## Назначение
Демонстрация понимания математических основ ML и умения реализовывать их в коде.
