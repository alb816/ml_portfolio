# Математические основы машинного обучения

Раздел содержит практические реализации и исследовательские ноутбуки по математике, которая используется в алгоритмах машинного обучения.

## Подразделы

### Линейная алгебра

[linear_algebra/](linear_algebra/)

Реализации и визуальные исследования:

- [vector_spaces/](linear_algebra/vector_spaces/) — RREF, ортонормированный базис, базис образа матрицы и визуализация ранга;
- [linear_systems/](linear_algebra/linear_systems/) — методы Якоби, Зейделя, Гаусса и ортогональная проекция;
- [eigenvalues_and_svd/](linear_algebra/eigenvalues_and_svd/) — собственные значения, собственные векторы и SVD;
- [transformations/](linear_algebra/transformations/) — матрицы перехода между базисами и аффинные преобразования;
- [vectors_and_distances/](linear_algebra/vectors_and_distances/) — исследовательский ноутбук с метриками расстояния;
- [hyperdimensional_computing/](linear_algebra/hyperdimensional_computing/) — экспериментальная реализация кодирования данных гипервекторами.

Подробное описание линейной алгебры находится в [linear_algebra/README.md](linear_algebra/README.md).

## Формат материалов

- `.py` — самостоятельные реализации алгоритмов;
- `.ipynb` — визуальные объяснения и эксперименты;
- `README.md` — теория, назначение и способ запуска.

## Цель раздела

Для каждой темы важно показать не только формулу, но и:

1. реализацию на Python и NumPy;
2. проверку результата на простых примерах;
3. сравнение с NumPy или scikit-learn;
4. связь с задачами машинного обучения.
