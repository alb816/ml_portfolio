# Проект A/B тестирования

Это небольшой проект в портфолио по экспериментальной аналитике и статистике. Он показывает типичную бизнес-задачу: сравнить контрольную и тестовую группу и понять, действительно ли изменение дало эффект.

## Цель проекта

В этом проекте показан полный цикл простого A/B-теста:

- генерация синтетических экспериментальных данных
- сравнение метрик между группами
- применение Welch's t-test
- интерпретация p-value и доверительного интервала
- формулировка бизнес-вывода

## Основные функции

Логика лежит в `src/ab_test.py`.

- `generate_data()` создаёт синтетические данные для control/treatment
- `run_ab_test()` считает средний lift, p-value и доверительный интервал
- `main()` запускает демо-вывод в консоли с интерпретацией результата

## Как запустить

Из корня репозитория:

```bash
python 04_experimentation/ab_testing/src/ab_test.py
```

Или через тесты:

```bash
pytest 04_experimentation/ab_testing/tests/test_ab_test.py
```

## Что именно показывает этот проект

Пояснение в формате, который важен для портфолио:

- как поставить гипотезу для эксперимента
- как сравнивать две группы по одному показателю
- как не путать “видимый эффект” с “статистически значимым эффектом”
- как правильно интерпретировать результат, а не просто смотреть на разницу средних

## Пример вывода

В консоли проект показывает не просто числа, а небольшую бизнес-историю:

```text
Результат A/B теста
----------------------------------------
Среднее A: 10.0000
Среднее B: 10.2000
Абсолютный эффект: 0.2000
Относительный эффект: 2.00%
Статистика Welch t: 2.5173
p-value: 0.011900
95% доверительный интервал: [0.0456, 0.3544]
Решение: эффект статистически значим, версия B выигрывает по сравнению с A.
Бизнесовый вывод: изменение выглядит полезным, но важно проверить, что это не случайный шум и что эффект устойчив на реальных данных.
```

Такой формат лучше подходит для портфолио, потому что он показывает не только код, но и понимание, как делать вывод из эксперимента.
