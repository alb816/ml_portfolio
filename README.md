# Портфолио по машинному обучению

Практическое портфолио кандидата на позицию junior ML engineer. Репозиторий разделён на математические основы, реализации алгоритмов с нуля, классическое машинное обучение и будущие инженерные проекты.

## Разделы

### 01 - Математические основы

Реализации и исследовательские ноутбуки по линейной алгебре, статистике и методам решения линейных систем.

Подробная навигация находится в [README раздела математических основ](01_math_foundations/README.md).

**Технологии:** Python, NumPy, Matplotlib

---

### 02 - ML с нуля

Реализация основных концепций машинного обучения без высокоуровневых ML-фреймворков.

**Реализовано:**

* Градиентный спуск
* Среднеквадратическая ошибка
* Автоматическое дифференцирование
* Двойные числа
* Прямое дифференцирование
* Векторизованные операции NumPy
* Двухслойный классификатор

**Технологии:** Python, NumPy

---

### 03 - Классическое машинное обучение

Комплексные проекты, охватывающие стандартный процесс машинного обучения:

```text
Данные
 ↓
Исследовательский анализ данных
 ↓
Очистка данных
 ↓
Разработка признаков
 ↓
Предварительная обработка
 ↓
Обучение модели
 ↓
Утверждение
 ↓
Оценка
```

Проекты включают:

* Бинарную классификацию
* Регрессию
* Логистическую регрессию
* Предварительную обработку признаков
* Оценку модели

**Технологии:** Python, NumPy, Pandas, Scikit-learn, Matplotlib

---

### 04 - Двухслойный классификатор

Реализация небольшой нейронной сети для классификации изображений в [02_ml_from_scratch/2_layer_classifier/](02_ml_from_scratch/2_layer_classifier/).

Проект направлен на изучение:

* прямого распространения
* обратного распространения
* функций активации
* бинарной кросс-энтропии
* вычисления градиента
* обучения с мини-батчами
* оптимизации параметров

**Технологии:** Python, NumPy

---

### 05 - Планируемые инженерные проекты

Раздел находится в планах. Предполагается добавить пример обслуживания обученной модели через REST API.

Планируемые компоненты:

* FastAPI
* Pydantic
* Docker
* сериализация моделей
* автоматизированные тесты

## Цель

Основная цель этого репозитория - продемонстрировать не только знание алгоритмов машинного обучения, но и умение структурировать, тестировать и развертывать код для машинного обучения.

## Как запускать примеры и тесты

Для запуска примеров и тестов локально:

1. Установите зависимости (рекомендуется в виртуальном окружении):

   ```bash
   pip install -r requirements.txt pytest
   ```

2. Запустите нужный `.py`-файл напрямую из его каталога или откройте соответствующий `.ipynb` в Jupyter.

3. Запустить тесты (pytest автоматически найдёт тесты):

   ```bash
   pytest -q
   ```

## CI (GitHub Actions)

Workflow в [.github/workflows/python-package.yml](.github/workflows/python-package.yml) устанавливает зависимости и запускает pytest на Python 3.10 и 3.11.
