# Градиентный спуск с нуля

Учебный проект, в котором линейная регрессия обучается градиентным спуском, а градиенты функции потерь вычисляются собственным движком автоматического дифференцирования в прямом режиме.

## Цель проекта

Показать полный минимальный цикл обучения модели:

1. вычисление предсказаний линейной модели;
2. вычисление MSE;
3. автоматическое получение градиента по параметрам;
4. обновление весов;
5. проверка результата на данных.

## Автоматическое дифференцирование

Дуальное число представляется как:

$$a + b\varepsilon,\qquad \varepsilon^2 = 0.$$

`a` хранит значение, а `b` — производную. Поэтому арифметические операции одновременно вычисляют значение функции и её производную.

В [dual_numbers.py](gradient_AD/dual_numbers.py) реализованы операции сложения, вычитания, умножения, деления, возведения в степень, экспоненты и суммирования.

Функция `gradient` создаёт единичные производные для параметров и возвращает значение функции вместе с градиентом.

## Градиентный спуск

Модель:

$$\hat{y} = Xw + b$$

Функция потерь:

$$L(w,b) = \frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)^2$$

Обновление параметров:

$$\theta_{t+1} = \theta_t - \eta\nabla L(\theta_t)$$

Реализация обучения находится в [gradient_descent.py](gradient_AD/gradient_descent.py).

## Запуск

Из каталога `02_ml_from_scratch/gradient_descent`:

```bash
python gradient_AD/gradient_descent.py
```

Запуск тестов из корня репозитория:

```bash
pytest 02_ml_from_scratch/gradient_descent/gradient_AD/test_dual_numbers.py -q
```

## Ограничения

- реализован forward-mode AD, который удобен для небольшого числа параметров;
- используется batch gradient descent;
- оптимизируется только MSE для линейной регрессии;
- воспроизводимость и история значения loss требуют отдельного улучшения.
